# Project Animal: куб-турель против волн врагов

> **Статус:** реализовано 2026-10-07 (сессия 2), проверено в headless-Chrome. Выложено на прод 2026-10-08.
> Отличия от плана: добавлен `src/entity.ts` (общий тип «тело + меш», удаление, синхронизация мешей).

## Context
Сейчас в проекте учебная сцена: куб на полу, пробел или касание делают прыжок, весь код в `src/main.ts`. Её превращаем в основу для игры «зачистка волн».

Неподвижный куб в центре сам отстреливается от врагов (тоже кубы), которые бегут к нему. Камера статичная, изометрическая. Делаем максимально просто, это фундамент под следующие шаги.

## Принятые решения (по итогам допроса)
| # | Тема | Решение |
|---|---|---|
| 1 | Структура кода | Модули по сущностям: `config`, `scene`, `physics`, `player`, `enemies`, `projectiles`, `hud`, `main` |
| 2 | Арена и спавн | Квадратный пол 24×24 м без стен. Враги появляются на невидимой окружности R = 11 м вокруг центра, сразу в кадре |
| 3 | Появление | По одному. Первый враг волны сразу, дальше каждые 0.6 с (постоянный интервал), каждый в случайной точке окружности |
| 4 | Размер волны | Тестовый: в волне n ровно n врагов (1, 2, 3, …). Скорость врагов не растёт |
| 5 | Смена волн | Волна закончилась, когда все её враги появились и убиты. Следующая начинается сразу, без паузы |
| 6 | Прицел | Автоматически в ближайшего врага по его текущей позиции, без упреждения. Перерасход снарядов на одного врага допустим |
| 7 | Баланс | Враг 2 м/с, выстрел раз в 1 с, снаряд 15 м/с. Ожидаемый проигрыш на волнах ~8–12 |
| 8 | Попадание | Снаряд убивает первого врага, которого коснулся (не обязательно свою цель), и исчезает сам. Промахнувшийся снаряд удаляется за пределами арены |
| 9 | Конец игры | Враг коснулся игрока: физика и стрельба замирают, рендер продолжается, оверлей «Игра окончена — волна N. Нажми, чтобы начать заново». Клик, касание или пробел запускают игру с волны 1 без перезагрузки |
| 10 | HUD | Только «Волна N» в левом верхнем углу, HTML поверх canvas |
| 11 | Визуал | Игрок — синий куб 1 м, враги — красные 0.8 м, снаряды — жёлтые 0.25 м, пол тёмно-серый, фон тёмный. Hemisphere- и Directional-свет, `MeshLambertMaterial`, без теней, игрок не поворачивается |
| 12 | Камера | `OrthographicCamera`, классическая изометрия, арена целиком в кадре при любом соотношении сторон |
| 13 | Физика | Rapier остаётся: враги толкаются, попадания через события столкновений |
| — | Удаляем | Прыжок (`JUMP_SPEED`, `jump`, обработчики), коллайдер пола |

## Модули
Стиль: функциональный, без классов, все функции типизированы, `const`, больше 2 параметров передаются объектом, импорты `./foo`, без `as`, boolean-переменные начинаются с `is`. Подробные учебные комментарии на русском, как в текущем `main.ts`.

- **`src/config.ts`**: `ARENA_SIZE = 24`, `SPAWN_RADIUS = 11`, `SPAWN_INTERVAL = 0.6`, `ENEMY_SPEED = 2`, `FIRE_INTERVAL = 1`, `PROJECTILE_SPEED = 15`, размеры `PLAYER_SIZE = 1`, `ENEMY_SIZE = 0.8`, `PROJECTILE_SIZE = 0.25`, цвета, `getWaveSize(wave) = wave`.
- **`src/scene.ts`**: `createScene()` возвращает `{ scene, camera, renderer }`, а также свет, пол-меш (`BoxGeometry` с тонкой высотой, верх на `y = 0`), фон. `fitCamera()`: камера в `(d, d, d)` смотрит в центр. `halfHeight = max(NEED_HALF_HEIGHT, NEED_HALF_WIDTH / aspect)`, `halfWidth = halfHeight * aspect`. Для пола 24×24 в изометрии нужно ~17×10 «полуэкранов», берём с запасом ~18×11. Обработчик `resize` обновляет камеру и размер рендерера.
- **`src/physics.ts`**: `createPhysics()` делает `await RAPIER.init()` и возвращает `{ world, eventQueue }`. У мира гравитация `{0, 0, 0}`, у `EventQueue` параметр `autoDrain = true`.
- **`src/player.ts`**: `createPlayer({ world, scene })` создаёт `RigidBodyDesc.fixed()` в `(0, PLAYER_SIZE/2, 0)` с cuboid-коллайдером и `ActiveEvents.COLLISION_EVENTS`, плюс меш.
- **`src/enemies.ts`**:
  - `spawnEnemy({ world, scene, enemies })` создаёт врага в случайной точке окружности: `dynamic().lockRotations().enabledTranslations(true, false, true)`, cuboid-коллайдер и меш;
  - `moveEnemies(enemies)` каждый кадр вызывает `setLinvel` с вектором к центру длиной `ENEMY_SPEED`;
  - `removeEnemy(...)` вызывает `world.removeRigidBody`, `scene.remove` и удаляет запись из `Map`.

  Хранилище — `Map<ColliderHandle, Entity>`.
- **`src/projectiles.ts`**:
  - `findNearestEnemy(enemies)` ищет врага, ближайшего к центру;
  - `fireProjectile({ world, scene, projectiles, target })` создаёт `dynamic()`-тело с коллайдером `setSensor(true)` и `ActiveEvents.COLLISION_EVENTS`; `setLinvel` задаётся один раз, направление на цель в плоскости XZ, длина `PROJECTILE_SPEED`;
  - `removeFarProjectiles(...)` удаляет снаряды, у которых `|x|` или `|z|` больше `ARENA_SIZE / 2 + 1`;
  - `removeProjectile(...)`.
- **`src/hud.ts`**: `createHud()` создаёт DOM-элементы и возвращает `{ setWave(n), showGameOver(n), hideGameOver() }`. Стили инлайном.
- **`src/main.ts`**: связывает модули и хранит состояние игры: `wave`, `spawnedInWave`, `spawnTimer`, `fireTimer`, `isGameOver`.

  Цикл игры на каждом кадре:
  1. `timer.update`;
  2. если не `isGameOver`:
     - спавн по таймеру, пока `spawnedInWave < getWaveSize(wave)`;
     - выстрел по таймеру, если враги есть;
     - `moveEnemies`;
     - `world.timestep = min(delta, 1/30)` и `world.step(eventQueue)`;
     - `drainCollisionEvents` только для `started`: пара «снаряд + враг» заносит обоих в `Set`-ы на удаление, пара «враг + игрок» ставит `isGameOver = true` и показывает оверлей; после drain удаляем всё из `Set`-ов;
     - `removeFarProjectiles`;
     - если волна полностью появилась и `enemies.size === 0`, начинается `wave + 1`;
  3. синхронизация мешей с телами;
  4. `render`.

  `resetGame()` удаляет всех врагов и снаряды, сбрасывает счётчики, начинает волну 1 и прячет оверлей. Вызывается по `pointerdown` на canvas и оверлее или по `Space`, только когда `isGameOver`.

Тип сущности: `type Entity = { body: RAPIER.RigidBody; mesh: THREE.Mesh }`.

## Verification
1. `npm run build`: `tsc` без ошибок.
2. `npm run dev` в браузере:
   - арена 24×24 целиком видна в изометрии, в том числе в портретном режиме (DevTools, мобильный режим) и после изменения окна;
   - в волне n появляется ровно n врагов по одному с интервалом 0.6 с, HUD показывает номер волны;
   - куб раз в секунду стреляет в ближайшего врага, попадание убивает врага, снаряд исчезает, промахи улетают и удаляются;
   - враги не проходят друг сквозь друга;
   - после последнего врага сразу начинается следующая волна;
   - на ~8–12 волне враг добирается до куба: всё замирает, оверлей показан, клик, касание или пробел начинают с волны 1;
   - в консоли нет ошибок.
