# Паттерны волн: формат описания и ручной список волн

> **Статус:** реализовано 2026-10-07 (сессия 2, продолжение), проверено в headless-Chrome:
> - формы на своих местах;
> - полный прогон 10 волн до победы, рестарт работает;
> - волны 3 и 8 проходятся в 3 из 3 прогонов.
>
> Закоммичено, выложено на прод 2026-10-08.
> Отличия от плана:
> - у волны есть поле `name`, оно показывается в HUD;
> - интервалы колец сокращены (волна 3 — 0.4 с, волна 8 — 0.6 с): с интервалом 1 с враги появлялись не быстрее, чем гибли, и кольца не было видно.

## Context
Сейчас враги волны появляются по одному в случайных точках окружности, а в волне n ровно n врагов.
Пользователь хочет, чтобы волны появлялись **паттернами** (по кругу, «то тут то там», узором и т. д.),
и нужен формат, в котором такие волны удобно описывать.

## Решения
| # | Тема | Решение | Кто решил |
|---|---|---|---|
| 1 | Источник волн | Конечный ручной список. Пройдены все волны — **победа**, враг дошёл до куба — поражение | пользователь |
| 2 | Что описывает группа | Две независимые оси: **форма** (где появляются) и **тайминг** (когда: разом или по очереди с интервалом в порядке формы) | пользователь |
| 3 | Формы | `circle` (кольцо/дуга), `random` (то тут то там), `line` (шеренга), `cluster` (кучка) | пользователь |
| 4 | Направления | Градусы относительно **экрана**: 0° — вверх, 90° — вправо, по часовой. Угол не указан — случайный | рекомендация (пользователь: «хватит вопросов, сделай лучшее») |
| 5 | Формат | TypeScript-данные в `src/waves.ts`: типы, автодополнение, комментарии рядом с волнами | сам |
| 6 | Пауза между волнами | Отдельной нет. Нужна пауза — `delay` у первой группы волны | сам |
| 7 | Отладка волн | `?wave=N` в адресе — игра начинается с волны N, рестарт тоже с неё | сам |
| 8 | HUD | «Волна N / M», экран конца игры показывает и поражение, и победу | сам |

## Формат
```ts
type Wave = { groups: SpawnGroup[] };

type SpawnGroup = {
  shape: Shape;       // ГДЕ
  delay?: number;     // КОГДА начинается группа, секунд от начала волны (по умолчанию 0)
  interval?: number;  // пауза между врагами группы; 0 или не указан — все разом
};

type Shape =
  | { type: 'circle'; count: number; angle?: number; arc?: number }   // кольцо (arc = 360) или дуга
  | { type: 'random'; count: number; angle?: number; arc?: number }   // случайные точки (можно ограничить сектором)
  | { type: 'line'; count: number; angle?: number; width?: number }   // шеренга поперёк направления на куб
  | { type: 'cluster'; count: number; angle?: number; radius?: number }; // кучка вокруг точки
```
- Все точки лежат на окружности спавна `SPAWN_RADIUS` или рядом с ней. Шеренга и кучка центрируются на ней.
- `circle`:
  - полное кольцо: первый враг стоит на `angle`, остальные идут по часовой (при отрицательном `arc` — против);
  - дуга (`|arc| < 360`): `angle` — её середина, крайние точки включены.
- `line`: порядок появления — слева направо, если смотреть от куба наружу, то есть по часовой.
- Случайный угол выбирается один раз на группу: вся фигура поворачивается целиком.

## Модули
- **`src/patterns.ts`** (новый):
  - тип `Shape`;
  - `getShapePoints(shape): Point[]` — функция на каждую форму;
  - перевод экранного угла в мировое направление (камера стоит в `(d, d, d)`, «вверх по экрану» на полу — это направление `(-1, 0, -1)`).
- **`src/waves.ts`** (новый): типы `Wave` и `SpawnGroup` с описанием формата в комментариях и список `WAVES` из 10 волн, по одной-две идеи на волну. Баланс прежний: выстрел раз в 1 с, враг 2 м/с, до куба ~5.5 с. Турель успевает убить ~5 врагов, появившихся разом, поэтому одновременных групп больше 4–5 врагов нет.
- **`src/schedule.ts`** (новый): `buildWaveSchedule(wave): SpawnEvent[]` превращает волну в отсортированный по времени список событий `{ time, x, z }`.
- **`src/enemies.ts`**: `spawnEnemy` принимает точку появления.
- **`src/config.ts`**: убрать `SPAWN_INTERVAL` и `getWaveSize`, добавить дефолты `DEFAULT_LINE_WIDTH` и `DEFAULT_CLUSTER_RADIUS`.
- **`src/main.ts`**:
  - состояние: `waveIndex`, `waveTime`, `schedule`, `nextSpawnIndex`, `fireTimer`, `status: 'playing' | 'lost' | 'won'`;
  - функции: `startWave`, `startGame` (она же рестарт), спавн по расписанию;
  - победа после последней волны;
  - чтение `?wave=N`.
- **`src/hud.ts`**: `setWave(wave, total)`, `showEndScreen({ title, hint })`, `hideEndScreen()`.
- **`README.md`**: как описывать волны.
