# Цифры урона над врагами

> **Статус:** реализовано 2026-10-07, сделано по плану. Проверено в headless-Chrome:
> - числа видны над полоской здоровья;
> - одновременно в DOM не больше 6 чисел, после конца игры — 0;
> - полный прогон до победы (~88 с), ошибок нет (кроме 404 на favicon).
>
> Закоммичено, выложено на прод 2026-10-08.
> При 7 попаданиях в секунду числа частично наезжают друг на друга. Настраивается через `DAMAGE_NUMBER_JITTER` и `DAMAGE_NUMBER_RISE`.

## Context
У врагов появилось здоровье (50 HP, попадание −10). Пользователь хочет видеть урон:
при попадании над врагом всплывает число.

## Решения (все приняты самостоятельно — пользователь дал только задачу)
| Тема | Решение | Почему |
|---|---|---|
| Чем рисовать | HTML-элемент поверх canvas, как HUD. Позиция — проекция точки над врагом на экран в момент попадания | Чёткий текст на любом экране, стили через CSS, не нужны текстуры со шрифтом |
| Анимация | Web Animations API (`element.animate`): за 0.8 с число поднимается на 40 px и плавно исчезает, потом элемент удаляется | Не нужен отдельный CSS с `@keyframes`, удаление по `onfinish` |
| Привязка к врагу | Только в момент появления, дальше число летит само | Так принято в играх; враг может умереть раньше, чем число исчезнет |
| Разброс | Случайный сдвиг по горизонтали ±12 px | При 7 попаданиях в секунду числа иначе лягут друг на друга |
| Вид | Белый жирный текст 18 px с тёмной обводкой (text-shadow) | Читается и на тёмном полу, и на красном враге |
| Где начинается | Чуть выше полоски здоровья | Не закрывает саму полоску |
| Экран конца игры | `z-index: 1`, чтобы досматривающие анимацию числа не рисовались поверх него | — |

## Изменения
- `src/config.ts`: длительность, подъём, разброс, высота над полоской, размер шрифта, цвет.
- `src/damage-numbers.ts` (новый): `createDamageNumbers()` возвращает функцию `showDamageNumber({ position, damage, camera })`.
- `src/main.ts`: после `damageEnemy` вызывать `showDamageNumber`.
- `src/hud.ts`: `z-index: 1` у экрана конца игры.
