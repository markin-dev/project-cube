# Пять типов врагов

> **Статус:** реализовано 2026-10-07, сделано по плану. Проверено в headless-Chrome: все 5 типов видны, ~95 FPS, ошибок нет. Закоммичено, выложено на прод 2026-10-08.
> **После реализации пользователь поправил числа руками:**
> - normal 40 HP;
> - big 2.2 кг / 80 HP;
> - brute 4 кг / 120 HP;
> - урон пули 15;
> - выстрел раз в 0.1 с;
> - множитель 2.
>
> Таблица ниже — исходный план.

## Context
Пока все враги одинаковые. Пользователь хочет 5 типов — «просто разные кубы с разными размерами, весом и HP».
Заодно временный множитель количества врагов для теста уменьшен с 5 до 3.

## Решения
| Тема | Решение | Кто решил |
|---|---|---|
| Множитель для теста | `ENEMY_COUNT_MULTIPLIER` 5 → 3 | пользователь |
| Типы | 5 типов в `ENEMY_KINDS` (config.ts): размер, масса, HP, цвет | пользователь (размер, вес, HP) / сам (цвет, числа) |
| Числа | Масса ≈ объём × та же плотность, что у обычного врага (~2 кг/м³). HP растёт с размером | сам |
| Цвет | Градиент по «тяжести»: от светло-оранжевого (крошка) до тёмно-бордового (громила). Не жёлтый (пули), не синий (игрок), не серый (призраки) | сам |
| Скорость | Одинаковая у всех — не просили | сам |
| Тип в волнах | Необязательное поле группы `enemy`. Не указано — у каждого врага случайный тип, поэтому существующие волны без правок стали смешанными | сам |
| Высота пули | Раньше пули летели на фиксированных 0.72 м и над крошкой (0.4 м) пролетали бы. Теперь куб стреляет на высоте `PROJECTILE_AIM_HEIGHT` = 0.9 роста цели; для обычного врага это те же 0.72 м | сам |

| Тип | Размер, м | Масса, кг | HP (попаданий) | Цвет |
|---|---|---|---|---|
| `tiny` — крошка | 0.4 | 0.125 | 10 (1) | `#fdba74` |
| `small` — мелкий | 0.6 | 0.42 | 20 (2) | `#fb923c` |
| `normal` — обычный | 0.8 | 1 | 50 (5) | `#ef4444` |
| `big` — крупный | 1.1 | 2.6 | 120 (12) | `#b91c1c` |
| `brute` — громила | 1.5 | 6.6 | 200 (20) | `#881337` |

Пуля весит 0.15 кг. Крошка и мелкий легче или сравнимы с ней, поэтому попадание их отшвыривает. Громилу пуля почти не сдвигает.

## Изменения
- `src/config.ts`:
  - тип `EnemyKind`, `ENEMY_KINDS`, `EnemyKindName`;
  - удалены `ENEMY_SIZE`, `ENEMY_MASS`, `ENEMY_MAX_HP`, `ENEMY_COLOR`;
  - `PROJECTILE_HEIGHT` → `PROJECTILE_AIM_HEIGHT`;
  - множитель 3.
- `src/enemies.ts`:
  - `Enemy.kind`;
  - геометрия и материал на каждый тип, создаются один раз;
  - всё, что зависело от размера (высота появления, «стоит на полу», высота полоски), считается по типу;
  - `ENEMY_KIND_NAMES` с type guard.
- `src/waves.ts`: поле группы `enemy?: EnemyKindName`.
- `src/schedule.ts`: у события расписания есть `kind`.
- `src/projectiles.ts`: высота выстрела по росту цели.
- `src/main.ts`: передаёт тип в `spawnEnemy`.

## Verification
- `npm run build`.
- Headless-Chrome: видны 5 типов разного размера и цвета, крошек отшвыривает, громилы почти не двигаются, пули попадают в крошек; ошибок нет.
