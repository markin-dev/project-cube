## Контекст

Четвёртый раздел ревью (Сессия 34). Пользователь: «Коммить и переходи к пункту 4».

## Сделано

- **Типы тестов проверяются.** `tsconfig.json` включает `unit/`, `browser/` и конфиги vite/vitest;
  `npm run typecheck` (= tsc) — первый шаг `npm test`, и `npm run build` тоже. Четыре старые ошибки
  типов ушли вместе с заглушками.
- **Покрытие измеряется.** `@vitest/coverage-v8` 5.0.3; `npm run test:coverage` (юниты) и
  `npm run test:coverage:e2e` (браузер). Было (юниты): 51% строк, sparks 76%, corpses 77%, entity 70%.
  Стало: логика 88–98% (sparks 91, corpses 88, entity 95, game 95, projectiles 95, enemies 94);
  UI, звук и main.ts — в браузерном покрытии (main 97, панель 83, звук 77, цифры урона 92).
- **Тесты по файлу на модуль, без заглушек.** `crit-damage` + `projectile-motion` + `fire-timer` →
  `projectiles.test.ts`; `enemy-bounds` + `movement` → `enemies.test.ts`. Враги и снаряды — настоящие
  (`unit/fixtures.ts`: мир Rapier, `spawnEnemy`, `fireProjectiles`); `spawnEnemy` теперь возвращает врага.
- **Новые юниты:** `corpses`, `entity`, `sparks` (читают матрицы InstancedMesh), `hp-bar`,
  `settings-panel` (каждый ключ конфига есть в панели, значения по умолчанию внутри диапазонов),
  `spawnEnemy`/`damageEnemy`, `fireProjectiles`, подбор места: поворот врага и «места нет».
- **Новые E2E:** `controls.test.ts` (пауза, рестарт кликом после поражения, выбор волны в панели),
  `sound.test.ts` (наборы и мут запоминаются, неизвестные и устаревшие наборы отбрасываются).
- **Убраны** тавтологичный тест «безопасная зона в описаниях волн» и дубль «тесно на полу»;
  дубли хелперов в `smoke.test.ts`.
- **Стиль по глобальному CLAUDE.md:** названия «Должен …» («Не должен» — для краевых случаев),
  один `expect` на тест, `it.each`, фейки UPPER_SNAKE_CASE, хелперы перед `afterEach`, без `as`.
- Комментарии `vitest*.config.ts` обновлены (убраны «Фаза 1/2», «tsc для тестов не нужен»).

## Найдено по ходу

- **ARENA_INSET не было в панели** — добавлен ползунок «Отступ спавна от стены» (0…5 м, «· волна»).
- **Подборщик мест: касание ровно на зазоре** считалось наложением из-за float32 в позициях Rapier
  (0.4 → 0.40000000596) — ярус над врагом пропускался. Добавлен допуск `SEPARATION_TOLERANCE` = 0.1 мм.
- `Matrix4.decompose` в three r186 возвращает масштаб 1 у вырожденной матрицы — тест искр читает
  масштаб по длине столбца.
