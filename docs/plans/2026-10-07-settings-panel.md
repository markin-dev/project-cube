# Панель настроек: весь конфиг меняется интерактивно

> **Статус:** реализовано 2026-10-07, сделано по плану. Проверено в headless-Chrome кликами по панели:
> - панель свёрнута и раскрывается;
> - скорость врагов 0 и цвет фона применяются сразу;
> - изменения переживают перезагрузку;
> - клики по панели после поражения не перезапускают игру;
> - копирование и «Сбросить всё» работают;
> - форматирование и безопасное слияние проверены отдельно в Node;
> - ошибок нет, частота кадров как у прошлого коммита.
>
> Закоммичено, на прод не выложено.
> Отличие от плана: сохранение по `onChange`, а не `onFinishChange` — у lil-gui для цвета `onFinishChange` срабатывает только при уходе фокуса.

## Context
Пользователь хочет панель, в которой можно менять весь конфиг игры прямо во время игры.
Сейчас `config.ts` — 41 константа `export const` (≈60 параметров вместе с полями типов врагов), их импортируют 13 модулей,
и многие значения «запекаются» при создании объектов (общие геометрии и материалы, коллайдеры, пол).

## Решения
| # | Тема | Решение | Кто решил |
|---|---|---|---|
| 1 | Где доступна | Везде, включая прод. По умолчанию свёрнута — видна только шапка «Настройки» | пользователь (свёрнута — сам) |
| 2 | Живое изменение уже живых врагов | Не нужно: размеры, массы и HP типов применяются к новым врагам | пользователь |
| 3 | Как меняются значения | Объект `DEFAULT_CONFIG` (числа и комментарии из кода) + рабочая копия `config`, которую меняет панель. Код читает `config.X` в момент использования. Имена полей прежние (`config.FIRE_INTERVAL`) | сам |
| 4 | Библиотека панели | lil-gui (~30 КБ, стандарт для three.js): ползунки, поля, выбор цвета, папки | сам |
| 5 | Когда применяется | Сразу: всё, что читается каждый кадр или выстрел. Сразу через обработчик: цвета, прозрачность призраков, гравитация. Новые враги: размер, масса, HP типов, трение, упругость, затухание, размеры полоски здоровья. Следующая волна: множитель, ширина шеренги, радиус кучки. Перезагрузка страницы: размер арены и игрока. Режим виден в подписи параметра | сам |
| 6 | Размеры без пересоздания геометрий | Общие геометрии единичного размера (1×1×1), размер задаётся масштабом меша. Тогда размер врага, пули и полоски — просто число при создании, а общие геометрии не нужно пересоздавать и освобождать | сам |
| 7 | Сохранение | В `localStorage` хранятся только отличия от `DEFAULT_CONFIG`: правки чисел в коде продолжают работать, если параметр не трогали в панели. Неизвестные и битые значения при загрузке отбрасываются. В шапке панели — число изменённых параметров | сам |
| 8 | Кнопки | «Скопировать изменения» — строки в формате `config.ts` для вставки в код. «Сбросить всё» — значения из кода. «Перезагрузить» — для параметров, которые применяются после перезагрузки | сам |
| 9 | Рестарт по клику | Клики и пробел внутри панели не перезапускают игру | сам |
| 10 | Живые враги | Тип копируется врагу при появлении, чтобы правка HP типа не меняла полоски уже живых врагов | сам |

## Изменения
- **`package.json`**: зависимость `lil-gui`.
- **`src/config.ts`**: `DEFAULT_CONFIG` (все поля с прежними комментариями), тип `Config`, `config` = копия дефолтов + сохранённые изменения. Типы `EnemyKind` и `EnemyKindName`.
- **`src/config-storage.ts`** (новый): загрузка и сохранение отличий, слияние только известных полей (type guards вместо `as`), подсчёт отличий, текст для копирования.
- **`src/settings-panel.ts`** (новый):
  - описание параметров по разделам (подпись, диапазон, шаг, когда применяется);
  - построение lil-gui и кнопки;
  - вызов `onChange` (живое применение) и сохранение.
- **Модули с общими материалами** — функции обновления цвета:
  - `scene.ts`: фон и пол;
  - `player.ts`;
  - `projectiles.ts`;
  - `hp-bar.ts`;
  - `corpses.ts`;
  - `enemies.ts`: материалы типов.
- **Остальные модули**: `CONST` → `config.CONST`; значения, вычислявшиеся при загрузке модуля, — в момент использования (кроме арены и игрока).
- **Единичные геометрии + масштаб**:
  - враг, пуля, полоска здоровья;
  - призрак хранит свой размер для сжатия.
- **`src/main.ts`**:
  - `applyLiveConfig()`: цвета и гравитация;
  - создание панели;
  - игнорирование кликов по панели при рестарте.
- **README, память, AGENTS**: описание панели.

## Verification
1. `npm run build`.
2. Headless-Chrome:
   - панель видна свёрнутой, открывается;
   - смена цвета фона — сразу;
   - скорость врагов 0 — враги стоят;
   - значение переживает перезагрузку;
   - «Сбросить всё» возвращает дефолты;
   - клик по панели на экране конца игры не перезапускает игру;
   - полный прогон с дефолтами без ошибок.
