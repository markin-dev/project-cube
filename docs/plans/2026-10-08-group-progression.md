# Группы волны: следующая начинается, как только предыдущие убиты; счётчик групп

> **Статус:** реализовано 2026-10-08, сделано по плану. Закоммичено, на прод не выложено.
> **Проверено в headless-Chrome** (по HUD, опрос раз в 100 мс):
> - волна 4, множитель 1, быстрая стрельба: «Группа 2 / 2» на 1.1 с вместо 5 с по задержке; в волне 5 группы шли с интервалом ~1 с вместо 5/10 с;
> - волна 4, медленная стрельба: вторая группа на 5.2 с — сработала задержка;
> - волна 10 («Финал»): группы на 3.0 / 4.8 / 10.1 с (задержки 5 / 9 / 15), потом победа;
> - HUD: «Волна N / M», под ней «Группа K / L», ниже название волны;
> - ошибок нет.

## Context
Группы внутри волны появлялись строго по `delay` (секунд от начала волны). Если куб быстро убивал группу,
он ждал, пока истечёт задержка следующей. Пользователь: «нужно добавить условие, что при смерти всех врагов
в группе надо спавнить следующую группу или запускать следующую волну, если это последняя группа;
также добавь счётчик групп под волнами».

## Решения
| Тема | Решение | Кто решил |
|---|---|---|
| Когда начинается группа | Что наступит раньше: её `delay` от начала волны (как было) или момент, когда все уже начавшиеся группы полностью появились и все их враги убиты. «Добавить условие», а не заменить задержку | пользователь / трактовка сама |
| Первая группа | Только по своей задержке: предыдущих групп нет, и `delay` первой группы остаётся паузой перед волной | сам |
| Группа, которая ещё появляется | Не считается убитой, пока не появились все её враги, — иначе смерть первого же врага запускала бы следующую группу | сам |
| Последняя группа | Как и было: волна зачищена — сразу следующая (или победа) | пользователь |
| Порядок | Группы начинаются строго по порядку списка в волне | сам |
| Счётчик | В HUD под «Волна N / M» — «Группа K / L», K — последняя начавшаяся группа | пользователь (место) / сам (формат) |

## Изменения
- `src/schedule.ts`: `buildWaveSchedule` возвращает группы `{ delay, events }`, время событий — от начала своей группы.
- `src/main.ts`:
  - в состоянии вместо общего расписания — группы `{ delay, events, startTime?, spawnedCount }`;
  - `startDueGroups` (запуск по задержке или по зачистке), `spawnScheduledEnemies` по группам;
  - `advanceWave`: все группы начались, все враги появились и убиты.
- `src/hud.ts`: строка группы, `setGroup`.
- `src/waves.ts`, README: описание `delay` с новым правилом.
