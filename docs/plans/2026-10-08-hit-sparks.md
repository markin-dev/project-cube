# Искры при попадании снарядов — план (2026-10-08)

Небольшие искры вылетают из точки, куда попал снаряд. Все параметры настраиваются в панели.

**Статус: реализован 2026-10-08, проверено в headless-Chrome, на прод не выложен.**
Отличия от плана: `SPARKS_SIZE` по умолчанию поднят с 0.06 до 0.1 (0.06 м ≈ 1.5 px — слишком мелко).

## Решения пользователя

| Вопрос | Решение |
|---|---|
| Как рисовать? | 3D в сцене (InstancedMesh), искры живут в игровом времени |
| Куда разлетаются? | Во все стороны от точки попадания (равномерно по сфере) |
| Какой набор параметров? | Основные 8 + цвет |

## Параметры (все — в `config.ts`, раздел «Искры», читаются в момент использования)

| Параметр | Смысл | Диапазон в панели |
|---|---|---|
| `SPARKS_COUNT` | искр на одно попадание, 0 — выключить | 0–30, шаг 1 |
| `SPARKS_LIFETIME` | время жизни, с | 0.05–3 |
| `SPARKS_SPEED` | начальная скорость разлёта, м/с | 0–30 |
| `SPARKS_SPEED_SPREAD` | случайная доля скорости каждой искры | 0–1 |
| `SPARKS_SIZE` | ребро искры-кубика, м (единичная геометрия + масштаб) | 0.01–0.5 |
| `SPARKS_SHRINK` | сжатие к концу жизни: 0 — размер постоянный, 1 — до нуля | 0–1 |
| `SPARKS_GRAVITY_SCALE` | гравитация искр доляю от `GRAVITY` | 0–2 |
| `SPARKS_DAMPING` | затухание скорости (сопротивление воздуха) | 0–10 |
| `SPARKS_COLOR` | цвет — раздел «Цвета» панели | выбор цвета |

## Реализация

1. **`src/sparks.ts` (новый модуль).** Пул частиц: `THREE.InstancedMesh` (единичный куб,
   `MeshBasicMaterial` — не зависит от света, выглядит светящимся), все искры — одним вызовом
   отрисовки. Пул фиксированный (1000), круговой указатель: при переполнении перезаписывается
   самая старая искра. Функции: `spawn(position)`, `update(delta)`, `clear()`, `refreshColor()`.
   Физика искры в `update`: гравитация × `SPARKS_GRAVITY_SCALE`, скорость гасится по
   `1 / (1 + damping × delta)` (не зависит от длины шага), пол — не даёт уйти ниже своей
   половины размера. Мёртвые искры обнуляются один раз (матрица с масштабом 0).
2. **`src/config.ts`** — раздел «Искры» (8 чисел) + `SPARKS_COLOR` в цветах.
3. **`src/settings-panel.ts`** — раздел «Искры» (все применяются сразу) + цвет в «Цвета».
4. **`src/main.ts`** — `createSparks({ scene })`; в `applyHit` перед удалением пули —
   `sparks.spawn(...)`; `sparks.update(delta)` внутри `updateGame` (пуause/ускорение действуют);
   `sparks.clear()` в `startGame`; `sparks.refreshColor()` в `applyLiveConfig`.
5. **Точка spawn:** не центр врага (искры были бы спрятаны внутри куба), а точка на поверхности
   куба в направлении от его центра на пулю: `t = (size/2) / max(|dx|,|dy|,|dz|)` — точка
   пересечения луча с гранью куба. Если враг уже мёртв (пуля догнала призрака) — точка пули.
6. **`README.md`** — строка про `src/sparks.ts` в списке модулей.

## Проверка

- headless-Chrome: искры видны при попаданиях, ошибок в консоли нет, FPS не просел;
- панель: все 8 ползунков и цвет меняют искры на ходу, «Сбросить всё» возвращает значения;
- пауза/×8: искры замирают/летят в игровом времени;
- `SPARKS_COUNT = 0` — искр нет; рестарт чистит сцену.
