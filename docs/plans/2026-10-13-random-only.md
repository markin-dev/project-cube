# Только случайная форма: удалены circle, polygon, perimeter

Дата: 2026-10-13. Статус: реализовано.

## Задача пользователя

«Давай упростим всё ещё сильнее. Удали все формы, кроме рандомной. Соответственно в каталоге сделай
несколько волн с разными настройками только этой формы.»

## Что делается

- `src/patterns.ts` сжат до одной формы `random` (count случайных точек, равномерно по площади кольца
  от края безопасной зоны до стены с отступом). Удалены `circle`, `polygon`, `perimeter` вместе с
  экранной геометрией (`getScreenDirection`, `getSpawnCirclePoint`), параметрами `distance`/`arc`/
  `sides`/`inset` и общим `jitter` — jitter оживлял регулярные контуры, у случайной формы он бессмыслен.
- `src/config.ts`: удалён `DEFAULT_POLYGON_SIDES`; `PERIMETER_INSET` переименован в `ARENA_INSET`
  (внешняя граница кольца random); комментарии приведены к одной форме. В панели слайдеров на оба
  ключа не было — панель не меняется.
- `src/waves.ts` переписан целиком: каталог-витрина 1–4 — одна форма с разными настройками
  («Форма: редкие», «Форма: частые», «Форма: по одному», «Форма: рой»); игровые 5–11 и демо 12–16
  переведены на random с сохранением таймингов и характера; нумерация не сдвинулась (`?wave=12` —
  «Громилы»).
- Тесты: `unit/patterns.test.ts` переписан (инварианты random + проверка волн на безопасную зону +
  два новых: count 0/1 и защитный clamp при съеденном зоной кольце), `unit/schedule.test.ts` —
  random вместо кругов.
- `README.md`: форма одна, пример волны, описание подборщика мест приведено к «столб вверх»
  (поправлено упущение Сессии 32).

## Проверка

`tsc --noEmit` + юниты + E2E + build; глазами: каждая волна через `?wave=N`.
