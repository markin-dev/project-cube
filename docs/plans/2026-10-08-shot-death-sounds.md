# Звуки выстрелов и смертей, свои громкости и муты, всё в панели

Дата: 2026-10-08
Статус: реализовано

## Задача

Пользователь: «Добавь звуки для выстрелов и для смерти врагов (не громкие, не навязчивые,
т.к. звуков много), так же по 5 паттернов звуков, похожие но не одинаковые.
Настройки звуков засунь в общую панель настроек. Если возможно — сделай громкость
для каждого типа звуков».

Уточнение по интерфейсу (задано одним вопросом): «Первый вариант, плюс для каждого типа
звука помимо своей громкости — свой дополнительный мут. В ряду около скорости мут общий»,
где «первый вариант» — весь выбор наборов уходит в панель, в ряду остаётся только 🔊.

## Решения

1. **Три типа звуков** (`SoundType = 'hit' | 'shot' | 'death'`): у каждого 5 наборов
   × 6 вариантов, свой характер. Наборы выстрелов (Щелчок, Пневма, Пила, Свист, Лазер)
   и смертей (Хлопок, Осколки, Гул, Звон, Пузырь) синтезируются тише попаданий:
   сумма пиков ≤ 0.3 (выстрелы) и ≤ 0.5 (смерти) против ~0.95 у попаданий.
2. **Тише и без кашы** — две страховки: низкие уровни в таблицах наборов + минимальная
   пауза `MIN_GAP_MS` между звуками одного типа (выстрел 50 мс, смерть 70 мс;
   у попаданий паузы нет — их частоту и так ограничивает FIRE_INTERVAL, поведение
   уже проверенного звука не меняли).
3. **Громкости и муты по типам — в config.ts**: `HIT_VOLUME/SHOT_VOLUME/DEATH_VOLUME`
   (по умолчанию 1 / 0.8 / 0.8 — выстрелы и смерти заданы тише) и
   `HIT_MUTED/SHOT_MUTED/DEATH_MUTED` (по умолчанию false). Общая `SOUND_VOLUME`
   и общий мут (кнопка 🔊 в ряду) — как были. Громкости читает `sound.applyVolume()`
   из `applyLiveConfig`, муты типов — `play()` в момент события, поэтому действуют сразу.
4. **Панель**: раздел «Звук» переехал из SECTIONS в отдельную функцию `addSoundSection`
   (к числам добавлены селекты наборов — состояние живёт в sound.ts, не в конфиге,
   как и выбор волны). Внутри — общая громкость + папка на тип: громкость, селект набора,
   чекбокс «Выключить звук». Для boolean в settings-panel добавлен тип `BooleanKey`
   (lil-gui сам рисует чекбокс). Кнопок наборов в ряду больше нет — sound-switch
   вернулся к одной кнопке мута.
5. **Звуки в игре**: `sound.playShot()` — в `shoot()` после `fireProjectile()`;
   `sound.playDeath()` — в `applyHit()` (пуля добила) и в `updateGame()` после
   `turnOutOfArenaIntoCorpses()` (считаем `corpses.size` до/после — массовая гибель
   = один звук на кадр, дальше сдерживает пауза).
6. **Наборы сохраняются** одним ключом `project-animal:sound-sets` (JSON
   `{ hit, shot, death }`); неизвестный id молча отбрасывается.

## Проверка (headless Chrome + CDP, скрипт shot-death-test.cjs)

- гейн-ноды при старте: `[0.5, 1, 0.8, 0.8]` — master и три типа в правильном порядке;
- все три типа звучат (4/4/4 подключения к гейнам);
- `SOUND_VOLUME 0.9` → первый гейн 0.9; `SHOT_VOLUME 0.25` → третий 0.25;
- мут выстрела: shot +0 за 3 с, hit +11, death +11; снятие мута → +6;
- переключение набора смерти при замьюченных попадании и выстреле → новые буферы
  запускаются только от смертей (117 → 119);
- пауза: FIRE_INTERVAL 0.01 → 3.5 зв./с (нехватка целей); ×30 врагов + быстрые пули
  → 18.5 зв./с при темпе стрельбы ~100/с (лимит ~20 — пауза работает, hit 48/с
  ушёл выше, потому что у попаданий паузы нет);
- перезагрузка: громкости `[0.9, 1, 0.25, 0.8]`, набор выстрела «Лазер» и мут
  выстрела пережили; HUD волны не уменьшился (панель не перезапускает игру);
- общий мут в ряду: все три типа замирают, после включения — оживают;
- `npm run build` и `npx tsc --noEmit` чистые; ошибок консоли нет (кроме штатного
  404 favicon).
