# Project Animal

Игра на TypeScript + Vite + Three.js + Rapier: куб в центре арены сам отстреливается от волн врагов.
Вид сверху в изометрии. Волны описаны вручную и появляются паттернами. У врагов есть здоровье,
попадания отбрасывают и опрокидывают их, погибшие становятся призраками. Враги, выбитые за край арены,
падают вниз. Прошёл все волны — победа, враг добрался до куба — поражение. Клик/касание/пробел начинают заново.

Врагов пять типов (`ENEMY_KINDS` в `src/config.ts`) — от крошки 0.4 м на 10 HP до громилы 1.5 м на 120 HP,
с разной массой и цветом.

Все числа — баланс, размеры, массы пуль и врагов, физику, цвета — можно менять в `src/config.ts`.

```bash
npm install
npm run dev
```

## Волны

Волны описываются в `src/waves.ts`. Волна состоит из групп, у каждой группы:
- `shape` — **где** появляются враги:
  - `circle` — кольцо или дуга;
  - `random` — то тут то там;
  - `line` — шеренга;
  - `cluster` — кучка.

  Параметры форм описаны в `src/patterns.ts`.
- `delay` — **когда** начинается группа, секунд от начала волны.
- `interval` — пауза между врагами группы. Не указан — все разом.
- `enemy` — **кто**: тип врагов группы (`tiny`, `small`, `normal`, `big`, `brute`). Не указан — у каждого врага случайный тип.

Углы — в градусах относительно экрана: 0° — вверх, 90° — вправо, по часовой. Без угла — случайный.

```ts
{
  name: 'С двух сторон',
  groups: [
    { shape: { type: 'line', count: 4, angle: 90 } },
    { shape: { type: 'line', count: 4, angle: 270 }, delay: 5 },
  ],
}
```

Чтобы проверить конкретную волну, добавь в адрес `?wave=N` (например, `http://localhost:5173/cube/?wave=4`) —
игра и рестарт начнутся с неё.

## Код

- `src/main.ts` — точка входа: состояние игры, смена волн, столкновения, игровой цикл, победа/поражение, рестарт
- `src/waves.ts` — список волн и описание формата
- `src/patterns.ts` — формы паттернов: по параметрам возвращают точки появления
- `src/schedule.ts` — превращает волну в расписание «когда и где появиться врагу»
- `src/config.ts` — все числа и цвета: размеры, скорости, интервалы, HP, физика и массы пуль и врагов
- `src/scene.ts` — сцена, изометрическая камера, свет, пол
- `src/physics.ts` — физический мир Rapier (гравитация, пол) и очередь событий столкновений
- `src/collision-groups.ts` — кто с кем сталкивается: пол, игрок, враги, снаряды, призраки
- `src/entity.ts` — общий тип «тело + видимый объект» и функции удаления/синхронизации
- `src/player.ts`, `src/enemies.ts`, `src/projectiles.ts` — игрок, враги (движение), пули (прицел, масса)
- `src/corpses.ts` — призраки погибших врагов
- `src/hp-bar.ts` — полоска здоровья над врагом
- `src/damage-numbers.ts` — всплывающие цифры урона
- `src/hud.ts` — надписи поверх игры: номер и название волны, экран победы/поражения
