# Project Cube

Игра на TypeScript + Vite + Three.js + Rapier: куб в центре арены сам отстреливается от волн врагов.
Вид сверху в изометрии. Волны описаны вручную и появляются паттернами. У врагов есть здоровье,
попадания отбрасывают и опрокидывают их, погибшие становятся призраками. Враг, выбитый за край арены
(граница видна как прозрачные красные стенки), сразу погибает. Прошёл все волны — победа, враг добрался до куба — поражение. Клик/касание/пробел начинают заново.

Врагов пять типов (`ENEMY_KINDS` в `src/config.ts`) — от крошки 0.4 м на 10 HP до громилы 1.5 м на 120 HP,
с разной массой и цветом.

Все числа — баланс, размеры, массы пуль и врагов, физику, цвета — можно менять в `src/config.ts`
или прямо в игре — в панели «Настройки» в правом верхнем углу (см. ниже).

```bash
npm install
npm run dev
```

## Волны

Волны описываются в `src/waves.ts`. Волна состоит из групп, у каждой группы:
- `shape` — **где** появляются враги. Форма одна — `random`: случайные точки по арене, равномерные
  по площади, вне безопасной зоны вокруг центра и не дальше стены с отступом (`ARENA_INSET` в `config.ts`).
  Параметры формы описаны в `src/patterns.ts`. Безопасная зона (`SAFE_RADIUS` в `config.ts`) —
  общее правило подборщика мест: внутрь её радиуса не появляется никто ни при каких условиях.
- `delay` — **когда** начинается группа: не позже стольких секунд от начала волны. Если все предыдущие
  группы уже появились и убиты раньше — следующая начинается сразу.
- `interval` — пауза между врагами группы. Не указан — все разом.
- `enemy` — **кто**: тип врагов группы (`tiny`, `small`, `normal`, `big`, `brute`). Не указан — у каждого врага случайный тип.

```ts
{
  name: 'Два наскока',
  groups: [
    { shape: { type: 'random', count: 5 } },
    { shape: { type: 'random', count: 5 }, delay: 2 },
  ],
}
```

Чтобы проверить конкретную волну, добавь в адрес `?wave=N` (например, `http://localhost:5173/cube/?wave=4`) —
игра и рестарт начнутся с неё.

Волну можно выбрать и во время игры: панель «Настройки» → раздел «Волны (отладка)» → селект «Волна».
Выбор запускает волну сразу, арена при этом очищается от врагов, снарядов и призраков. Кнопка
«Перезапустить волну» перезапускает выбранную волну. После выбранной волны всё идёт как обычно —
следующая начнётся сама. Селект показывает текущую волну.

## Скорость игры

Кнопки в левом нижнем углу: ⏸ (пауза), ×0.5, ×1, ×2, ×4, ×8. Физика и темп стрельбы при ускорении такие же,
как на обычной скорости, — просто больше шагов за кадр (и выше нагрузка). Ниже 10 FPS игра замедляется.

## Звук

Звуков три типа: **попадание** снаряда в живого врага, **выстрел** куба и **гибель врага** — у каждого
5 наборов звучания, по умолчанию «Кирпич», «Щелчок» и «Хлопок». Наборы выстрелов — Щелчок, Пневма,
Пила, Свист, Лазер; смертей — Хлопок, Осколки, Гул, Звон, Пузырь. Всё это настраивается в разделе
«Звук» панели настроек: общая громкость, а в папке каждого типа — своя громкость, свой мут
(чекбокс «Выключить звук») и выбор набора. Слева в ряду скорости — только общий мут 🔊 / 🔇.
Громкости и муты (`HIT_VOLUME`, `SHOT_VOLUME`, `DEATH_VOLUME`, `*_MUTED` в `src/config.ts`)
применяются сразу, наборы и mute запоминаются в браузере и переживают перезагрузку.

Звуки синтезируются Web Audio прямо в браузере, ассетов нет. Внутри набора — 6 похожих, но
не одинаковых вариантов: каждый раз берётся случайный (никогда не повторяющий предыдущий
подряд) и играет с немного разной скоростью. Выстрелы и смерти звучат тише попаданий: их много,
поэтому у них низкие уровни синтеза и штатные громкости 0.8. У каждого типа есть минимальная пауза
между звучаниями (попадание 30, выстрел 50, смерть 70 мс) — частый поток не превращается в кашу. Звук появляется после первого
клика или нажатия — таково правило autoplay в браузерах.

## Панель настроек

Кнопка «Настройки» в правом верхнем углу раскрывает панель со всеми параметрами из `src/config.ts`.
Пометка в подписи — когда изменение применится: без пометки — сразу, «· новые» — для новых врагов,
«· волна» — со следующей волны, «· перезагрузка» — после перезагрузки страницы.

Изменения сохраняются в браузере (только отличия от значений из кода) и переживают перезагрузку.
«Скопировать изменения» кладёт в буфер строки в формате `config.ts` — их можно вставить вместо прежних,
«Сбросить всё» возвращает значения из кода.

## Код

- `src/main.ts` — точка входа: собирает физику, сцену и интерфейс, создаёт игру, ввод (рестарт), цикл кадров
- `src/game.ts` — игровая логика без DOM и рендера: состояние, смена волн и групп, стрельба, столкновения, победа/поражение, шаг симуляции (тестируется на headless-Rapier)
- `src/waves.ts` — список волн и описание формата
- `src/patterns.ts` — форма спавна (random): по параметрам возвращает точки появления
- `src/schedule.ts` — превращает волну в расписание «когда и где появиться врагу»
- `src/spawn-placement.ts` — если точка появления занята, ставит врага ярусом выше (столб растёт вверх), а при необходимости — двигает к ближайшему свободному месту
- `src/config.ts` — все числа и цвета (`DEFAULT_CONFIG`) и рабочий конфиг `config`, который читает игра
- `src/config-storage.ts` — сохранение изменений из панели в браузере, текст для копирования в код
- `src/settings-panel.ts` — панель настроек (lil-gui): разделы, диапазоны, когда применяется каждый параметр
- `src/scene.ts` — сцена, изометрическая камера, свет, пол
- `src/physics.ts` — физический мир Rapier (гравитация, пол) и очередь событий столкновений
- `src/collision-groups.ts` — кто с кем сталкивается: пол, игрок, враги, снаряды, призраки
- `src/entity.ts` — общий тип «тело + видимый объект» и функции удаления/синхронизации
- `src/player.ts`, `src/enemies.ts`, `src/projectiles.ts` — игрок, враги (движение), пули (залп по разным врагам — по одному снаряду на каждого, прицел с упреждением и разбросом, масса)
- `src/corpses.ts` — призраки погибших врагов и смерть при пересечении края арены
- `src/death-walls.ts` — прозрачные стенки «границы смерти» по краям арены (только для вида)
- `src/hp-bar.ts` — полоска здоровья над врагом
- `src/damage-numbers.ts` — всплывающие цифры урона
- `src/sparks.ts` — искры при попадании снарядов: пул частиц на InstancedMesh, живут в игровом времени
- `src/hud.ts` — надписи поверх игры: номер и название волны, счётчик групп, экран победы/поражения
- `src/speed-switch.ts` — переключатель скорости игры в левом нижнем углу
- `src/sound.ts` — звук: три типа (попадание, выстрел, смерть), у каждого 5 наборов по 6 вариантов,
  синтез Web Audio без ассетов, свои громкости и муты из config, паузы между частыми звуками,
  общий mute и сохранение выбора наборов в браузере
- `src/sound-switch.ts` — кнопка общего мута 🔊/🔇 в ряду переключателя скорости
- `src/fps-counter.ts` — счётчик FPS в правом нижнем углу (реальное время кадра, обновление раз в 0.5 с)
- `src/layout.ts` — раскладка под ширину экрана: на узком панель внизу, кнопки и FPS над ней; перестраивается при повороте и ресайзе
